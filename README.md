# MonVibe

**MonVibe** adalah aplikasi web berbasis *Single Page Application* (SPA) yang dirancang khusus untuk membantu mahasiswa atau pengguna umum dalam memantau pengeluaran harian, mengontrol batas anggaran bulanan (*budgeting*), serta menjaga kesehatan finansial dengan tampilan yang modern dan responsif.

## Fitur Utama
* **Dashboard Finansial Real-Time:** Menampilkan ringkasan Total Saldo Rekening, Limit Anggaran Bulanan, Pengeluaran Bulan Ini, dan Sisa Limit secara instan.
* **Sistem Peringatan Otomatis (Alert):** 
  * Status **Aman** (Hijau) jika pengeluaran di bawah 80%.
  * Status **Waspada** (Merah) dan peringatan khusus saat pengeluaran melewati 80%.
  * Status **Limit Habis** (Merah Kritis) saat pengeluaran mencapai atau melewati 100% dari batas anggaran.
* **Formulir Transaksi & Validasi Saldo:** Memasukkan keterangan belanja dan nominal lengkap dengan validasi input serta pengecekan sisa saldo rekening secara otomatis.
* **Format Mata Otomatis Rupiah:** Mengubah angka mentah menjadi format mata uang Rupiah (`Rp X.XXX.XXX`) secara akurat.
* **Fitur Pencarian Instan (Live Search):** Mencari riwayat daftar transaksi berdasarkan kata kunci secara *real-time* tanpa perlu memuat ulang (*reload*) halaman.
* **Notifikasi Pop-up (*Toast Notification*):** Memberikan umpan balik visual saat pengguna berhasil menambah atau menghapus data transaksi.

##  Teknologi yang Digunakan
* **HTML5:** Struktur semantik kerangka halaman web.
* **CSS3:** Desain antarmuka modern, warna tema, dan tata letak responsif menggunakan *CSS*.
* **JavaScript (ES6):** Logika pemrograman interaktif, manipulasi DOM, manajemen data menggunakan *Array of Objects*, dan fungsi kalkulasi otomatis.

## Cara Menjalankan
Jika ingin menjalankan kode program ini langsung di komputer lokal:
1. Unduh (*clone*) atau *download* repositori ini.
2. Buka folder proyek menggunakan teks editor seperti **Visual Studio Code (VS Code)**.
3. Jalankan file `index.html` menggunakan ekstensi **Live Server** di VS Code, atau cukup buka file `index.html` langsung melalui peramban web (*browser*) seperti Google Chrome.
